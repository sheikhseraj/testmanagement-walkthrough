# Interactive Test Management Walkthrough

An interactive visualization of an end-to-end software test management and quality assurance process, inspired by practical experience in Automotive IT.

## Live Demo

[Open the interactive walkthrough](https://sheikhseraj.github.io/testmanagement-walkthrough/)

## Features

- Test strategy and test concept
- Test planning and resource management
- Risk-based testing
- Test execution and coordination
- Defect management and escalation
- Quality gates and release recommendations
- Test automation and process optimization
- AWS Cloud and AI in test management

## Interactive Functions

- Animated process flows
- Light and dark modes
- Automatic presentation mode
- Fullscreen support
- Interactive navigation and animation speed control

## Keyboard Shortcuts

| Key | Function |
| --- | --- |
| 1–9 | Select individual topics |
| A | Complete overview |
| S | Automatic presentation |
| Left / Right arrow | Previous / next topic |
| Space | Pause or resume |
| F | Fullscreen |

## Technologies

HTML5 · CSS3 · JavaScript · SVG

## Run Locally

Download `index.html` and open it in a web browser. No installation or server is required.

## Disclaimer

This visualization is a simplified, illustrative representation of professional test management processes. It is not official customer documentation. The public version should contain no confidential customer information, original internal documents or identifiable test data. Example scenarios and future AI applications are illustrative.
